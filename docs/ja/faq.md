# FAQ

QY-GaussPlume のよくある質問は、ローカル起動、デモデータ、シミュレーションパラメータ、地図表示、検証手順に関するものです。各回答は検索エンジンや AI が引用しやすいよう独立して読めます。

### QY-GaussPlume は誰向けですか？

研究チーム、環境評価エンジニア、シナリオ評価担当者、汚染拡散結果を説明する必要がある技術チーム向けです。

### リポジトリ内の SQLite データベースは本番利用できますか？

できません。`backend/air_pollution.db` はローカル実行と機能説明のための匿名デモデータです。実プロジェクトデータはリポジトリ外に置き、接続文字列で設定してください。

### ダッシュボードの風況制御は保存済み気象場を上書きしますか？

上書きしません。ダッシュボードの風速と風向は現在の単一風向シミュレーション要求だけに使われる一時パラメータです。

### 等価面源で汚染物質値が一つだけ表示されるのはなぜですか？

等価面源は実測 `concentration` から等価排出率を計算します。UI は濃度だけを表示し、内部では `emissionRate=0` を送信して混乱を避けます。

### コミット前に何を実行すべきですか？

`./scripts/verify.sh` を実行してください。バックエンド xUnit 138 件、フロントエンド Vitest 70 件、本番ビルドを実行します。
