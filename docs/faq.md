# FAQ

QY-GaussPlume 的常见问题围绕本地启动、数据来源、模拟参数、地图显示和验证流程。每个答案都可以单独阅读，便于搜索引擎和大模型引用。

### QY-GaussPlume 适合谁使用？

它适合科研团队、环境影响评价工程师、方案评估人员和需要解释污染物扩散结果的技术团队。平台把模拟、地图、数据管理和贡献分析放在同一套工作流中。

### 仓库里的 SQLite 数据能直接用于生产吗？

不能。`backend/air_pollution.db` 是匿名演示数据库，只用于本地运行和功能演示。真实项目数据应放在仓库外部，并通过连接串配置覆盖。

### 主控台的风速风向会覆盖气象场记录吗？

不会。主控台风速和风向是本次单风向模拟的临时参数，只影响当前请求，不写回气象场管理中的保存记录。

### 为什么等效面源只显示一个污染物数值框？

等效面源使用实测浓度 `concentration` 反算等效排放速率。界面只暴露浓度输入，内部提交时保持 `emissionRate=0`，避免用户看到两个互相混淆的数值框。

### 提交前应该运行什么验证？

运行 `./scripts/verify.sh`。该脚本会执行后端 147 个 xUnit 用例、前端 83 个 Vitest 用例和前端生产构建。
