# QY-GaussPlume

QY-GaussPlume is an air-pollution dispersion simulation platform for research and engineering assessment. It connects ASP.NET Core 9, Vue 3, Leaflet, and a Gaussian plume model into a verifiable workflow for source management, meteorology, simulation, and contribution analysis.

## Use Cases

- Compare emission sources and wind conditions during environmental assessment.
- Discuss engineering options with concentration fields and receptor impact visible on a map.
- Reproduce model scenarios for research, teaching, or delivery review.
