# Vue2 与 Vue3 功能对齐清单

本清单用于后续导出和集成前逐项核对 `frontend-vue/`（Vue3）与 `frontend-vue2/`（Vue2）的功能差异。

## 已完成对齐

### 主控台

- 顶部状态栏与地图工具条合并展示。
- 固定区域切换、底图切换、气象场选择。
- 单风向 / 多风向模式，支持 8 / 16 / 32 / 64 / 72 风向。
- 计算污染物筛选。
- 右侧气象控制窗口、风向圆盘、风速与来风方向临时输入。
- 运行模拟时透传当前风速、来风方向、模拟范围、网格分辨率和模拟高度。
- 模拟结果、污染物浓度切换、扩散浓度色阶控制、空气站点污染源贡献排名、贡献分析入口和公式说明入口。
- 地图仅显示启用排放源和启用受体点。

### 排放源管理

- 区域标签、新增、编辑、删除、批量删除。
- 全部启用、全部停用和单行启用开关。
- 源类型筛选：包含“全部类型”，选择后需点击“确定”才生效。
- 按源类型下载模板和批量导入。
- 点源、面源、等效面源、线源专属字段。
- 污染物子表；等效面源使用测量浓度，普通源使用排放速率。
- 批量操作使用 `Promise.allSettled`，允许部分失败后刷新列表并提示。

### 受体点管理

- 列表、新增、编辑、删除、删除确认。
- 批量删除、批量删除确认、部分失败提示。
- 下载模板、批量导入、导出选中受体点。
- 全部启用、全部停用和单行启用开关。
- 标记图标、标记颜色、高度等字段。

### 气象场管理

- 列表、新增、编辑、删除、删除确认。
- 批量删除、批量删除确认、部分失败提示。
- 全部启用和单行启用开关。
- 风速、来风方向、稳定度、边界层高度、温度、湿度、云量、降水字段。

## 已部分对齐，建议继续精修

- Vue2 目前以 Element UI 组件完成业务功能对齐，视觉细节与 Vue3 Element Plus 版本仍可能存在像素级差异。
- 气象场管理 Vue3 当前没有“全部停用”，Vue2 也保持一致；如果产品需要，可后续显式新增。

## 2026-06-26 追加核验记录

- 主控台顶部工具条：补齐与 Vue3 对齐的 `data-test` 锚点，便于后续按 Vue3 用例迁移自动化测试。
- 扩散浓度色阶：Vue2 `ColorLegend` 已改为使用与 Vue3 相同的 `steppedGradientColor` 分段色阶，并展示标题、单位、最小/中值/最大刻度。
- 多风向对话框：Vue2 `ParallelSimulationDialog` 已从兼容占位恢复为可运行入口，支持气象场、统一风速、8/16/32/64/72 风向、自定义权重、聚合返回和完成事件；同时保留主控台顶部直接运行多风向入口。
- 计算污染物下拉：Vue2 与 Vue3 均默认包含 PM2.5、PM10、TSP、VOCs、NOx、O3，并合并当前数据/结果里的其它污染物，避免当前区域缺少某类源时无法选择该污染物。

### 当前仍需注意

- Vue2 当前目标是业务功能可用和可集成；与 Vue3 的 Element Plus 版本仍可能有像素级差异。
- Vue3 原有自动化测试覆盖更细，Vue2 目前采用静态回归检查 + 构建验证；如后续继续长期维护，建议增加 Vue2 组件级交互测试。
- `ParallelSimulationDialog.vue` 在 Vue2 中保留为兼容弹窗，主流程已改为顶部工具条直接运行多风向。
